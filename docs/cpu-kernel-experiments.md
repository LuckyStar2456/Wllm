# 低内存 CPU 算子实验

2026-10-24，为 E3-01/E2-03 增加独立 `wllm-cpu-kernel-bench`。它不加载完整模型，不分配 KV/循环状态或模型上下文，不链接进 `wllm.exe`；原推理可执行文件、本机配置、Q4_K_M/16K/思考与采样设置保持不变。首轮结果及失败记录见[本轮报告](../reports/cpu-kernel-validation.md)。

## 实验范围

从当前 GGUF 原样读取一个连续的二维 Q4_K 权重矩阵，使用确定性的合成 F32 激活。激活转换复用固定 ggml 的 Q8_K 实现及按块线程划分；Q8_K 是参照路径既有的中间计算类型，不是新增权重量化。当前三种实际形状是 FFN gate `[4096,12288]`、SSM output `[4096,4096]`、attention Q `[4096,8192]`，每种测 1/2/3/7/8/128 列输入。Q4_K_M 文件还有 Q6_K 等张量，本实验不覆盖这些类型，不代表整个混合模型。

输入是合成激活，不能称为实际前向轨迹重放。完整算子输出要求有限且逐字节等于同构建上游 `ggml_mul_mat`；不放宽既有整模型 logits 门槛，也不以算子相同推定任务质量已验收。

## 两列共享解包候选

`experiments/q4_pair.cpp` 基于固定上游的 MIT AVX2 点积路径，复用两列之间的 Q4 解包、scale/min 解码，保持各列原有 lane 累加、FMA 与归约顺序。16 行局部块用于保留权重局部性。保留同样调度但分别调用原点积的对照，以区分解包复用和循环调度变化。

源码核对发现：当前上游 `tiled/tiled.cpp` 默认在输入列数至少为 8 时采用 tiled 矩阵核。最初试图整体替换的实验未通过字节相等门槛，因此候选收窄到 **2–7 列的原点积路径**。1 列解码及至少 8 列输入直接保留上游。不是禁用 tiled 后挑选较慢参照，也没有修改 vendor 或环境默认值。该候选没有稳定性能收益，保持在独立实验目标中，不进入引擎。

非候选形状下，两个候选位置实际上重复执行相同上游图，报告标为 `unchanged_upstream_control`。它们用于观察计时波动，其耗时差不能算候选收益。环境若禁用默认 tiled 或强制小批量 tiled，实验明确拒绝。

## 线程筛选和资源边界

线程扫描使用同一个容量为 8 的驻留 CPU 池，分别以 1/2/4/8 个活动线程执行上游矩阵图；poll 保持上游默认 50。基准为 4 个活动线程。线程池容量、活动线程、计划工作区和实际进程峰值均入报告。这个算子池不等于默认推理中每次图执行的临时池，不能从这些值推定默认完整请求的提速。

每个 profile 独立预热两次，9 轮按 profile 正序/逆序交替执行；小矩阵每个计时样本连续调用 16 次后取每次均值。计时包含 Q8_K 激活转换、图执行和线程同步；读取权重、建图/计划、分配/建池及输出核对另在计时之外。每个计时样本末尾再次核对完整输出，输出相等失败即停止，不给失败候选跑性能。只做筛选，不计算可靠尾延迟、统计显著性或正式模型性能。

单个权重不超过 64MiB，实验分配载荷不超过 256MiB，开始与每轮均检查额外的 1GiB 物理/提交余量。进程峰值另报，载荷上限不冒充整个进程内存上限。这是独立小算子的准入，不替换或放宽完整模型原有的保守预算。

8 线程输入计算可保留为待验收配置，使用现有 `threads_batch=8`，生成继续 `threads=4`，其他执行开关仍关闭。`benchmarks/cpu-prefill8-profiles.json` 为后续完整模型对照准备；当前不改默认线程，也不把本轮孤立算子计时写为整模型 token/s 或 TTFT。

## 复现

```powershell
# 明确构建独立实验，并运行 126 组小矩阵数值/分流检查
./scripts/build.ps1 -CpuKernelExperiments

# 不加载模型权重的数值与入口检查
py -3.11 -B -m unittest tests/test_cpu_kernels.py

# 只读本机现有 GGUF 中选定矩阵，不执行整模型推理
py -3.11 -B scripts/benchmark_cpu_kernels.py

# 后续资源准入满足时，才进行完整请求对照；当前资源不足会拒绝预热
py -3.11 -B scripts/benchmark.py --profiles benchmarks/cpu-prefill8-profiles.json --cases short medium --repeats 3
```

后续若继续筛选 8 线程输入，先增加 Q6_K、完整注意力/循环层、归一化及混合图的低内存参照，观察同实现控制组的噪声；再在原精度、16K、模板与采样下进行完整 logits、任务质量、峰值和交替重复端到端验收。前缀缓存、失败的重排/AVX512/GPU 候选均不因本实验而启用。
