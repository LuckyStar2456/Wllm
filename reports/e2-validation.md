# Wllm 0.2：首批 CPU 基础优化

日期：2026-10-10。已在原 Windows / i5-1135G7 / 16GB 机器构建并验证。保留 Qwen3.5 Q4_K_M 文本权重、F16 状态、思考和原采样配置，默认上下文 4096，未修改上游源码、Ollama 配置或下载替代模型。完整 E2、GPU 后端和跨引擎性能对照尚未完成。

## 已实现与采用决定

- 新增 `-Interactive`：保留已加载模型，在同一进程连续处理独立请求。每个请求重新创建上下文、KV/循环状态、采样器与计量，不携带历史或复用前缀。该模式为显式选择；默认单次运行仍结束即释放。
- 新增输入阶段独立线程数、线程池复用、中间 logits 跳过开关、实际配置记录与 logits 数值诊断。
- 新增固定负载、单项/组合消融、分阶段线程/批次筛选、逐轮反转顺序、原始记录及中位数/范围汇总工具。失败和不完整固定步数样本不进入成功性能统计。
- 保留默认 4 线程 / 批次 128 / AVX2。两项执行开关正确性通过，但未证实稳定提速，默认关闭；2 生成线程、256 批次与 8 输入线程也未获充分采用依据。
- AVX512/VBMI/VNNI 的硬件支持与构建已核实，但未通过本轮数值门槛，因此仅保留研究构建选项，已恢复 AVX2 运行程序。

## 连续独立请求的实测收益

三轮交替分组，每轮对照三个独立进程与一个包含三个请求的驻留进程；共 18 次请求。用 18/22 token 的中英文短提示词，seed=42、每次固定生成 32 token。三个请求包括 A、B、A，检查前一请求不会污染下一请求。下表取每轮后两个请求，共每种模式 6 个样本的中位数。

| 指标 | 每次单独运行 | 复用已加载模型 | 解释 |
|---|---:|---:|---|
| 加载/准备 | 1.228 s | 0.042 s | 后续请求仍计模板和新上下文准备；减少约 96.6% |
| 输入处理 | 2.762 s | 2.240 s | 不复用输入 token，驻留权重避免重新触页等开销 |
| 首 token | 4.073 s | 2.423 s | 减少约 40.5%；首次加载不享有此收益 |
| 持续生成 | 4.798 token/s | 4.813 token/s | 基本相当，不声称解码算子已加速 |
| 请求耗时 | 11.292 s | 8.955 s | 驻留请求不在末尾卸载模型，不能独立当成完整会话成本 |
| 采样峰值工作集 | 约 4.89 GiB | 约 4.89 GiB | 驻留模式在等待输入时仍占用模型内存 |

将最终模型释放耗时计回三个请求的整段会话，三轮分别为 **33.61 → 28.27 s、32.43 → 28.86 s、37.01 → 29.96 s**，减少约 11%–19%。这些总和不含用户输入等待、进程和后端初始化，不称冷盘端到端基准。会话释放分别为 0.750、0.743、0.766 s。

模型权重与驻留/独立模式所有对应请求的 token 序列相同。样本少、系统文件缓存和后台负载未受控，性能范围见[机器可读汇总](e2-summary.json)。尚未完成接近 4K 的长文任务质量或长期稳定性评测，也没有同条件 Ollama 加速倍数结论。

## 正确性与筛选证据

- 最终 AVX2 构建及 25 项原生检查通过；8 个原型集成用例通过，覆盖完整思考回答、模板、输入与生成边界、失败、超时、取消和计量。
- 驻留模式 3 个测试分批通过：三轮独立状态/性能对照、第二次请求失败释放、第二次生成取消释放。实际 PowerShell 交互终端验证了中文连续输入、`reused` 实时显示、参数转发、`/exit` 与模型释放，验证结束后无残留推理进程。
- 16 token greedy 诊断仍与未修改的上游 `examples/simple` 输出一致。基准汇总测试通过，确认失败及缺失吞吐不会伪装成更快的成功样本。
- CPU 执行开关的 2 个输入 × 5 种配置共 10 组诊断：每组比较 248,320 个最终输入 logits，最大绝对差异均为 0；16 个生成 token、正文及多批状态连续性一致。包括不同的输入/生成线程数。
- 运行时保持原采样链；检查未通过时不切换 greedy 或关闭思考。
- AVX512 诊断预设绝对/相对容差为 `1e-3` / `1e-4`、原始 softmax KL 上限 `1e-6`。第一个输入观察到最大差异 **1.22393**、KL **0.0001391**，虽然 32 个生成 token 相同，仍判定未通过并停止采用；没有事后放宽阈值。
- 单项开关与组合、线程与批次各完成一轮短/中输入筛选，只用作候选筛选，不据单次波动宣布提速。

原始二进制、逐 token / logits、提示词和日志留在本地 `reports/`。当前程序 SHA256：`5a3a3855419e710d9cd97777e5d552c47c217bc4894a85dd7c20d87777703209`；依赖版本与原模型身份不变。
