# 首批硬件性能推进：CPU 前缀快照实验候选

日期：2026-10-24。基于 `898350e` 推进 E3-03/E3-07C 的最小 CPU 实验候选。**实现已加入，默认关闭；真实缓存恢复、数值、隔离和性能未验收。** 本轮不存在可采用的缓存加速倍数。用户在内存阻断后明确选择“先保留默认关闭的候选，记录未验收”，因此没有继续重试缓存模型测试、降低精度/上下文/余量或关闭其他应用。

## 1. 硬件与本轮范围

本机重新枚举为 i5-1135G7（4 核 8 线程）、约 16GB 物理 RAM、Iris Xe；还有虚拟显示接口，不能视为额外计算卡。未发现 NVIDIA 实卡。首批覆盖优先级仍为 x86 CPU、Intel GPU、NVIDIA GPU，但本轮没有新增 GPU 适配或验证。Iris Xe Vulkan 保持原数值失败候选关闭，NVIDIA 缺少实机验证条件；不以 CPU 结果推定任一 GPU 已兼容或提速。

保留当前 Qwen3.5-9B 文本 GGUF Q4_K_M、16384 上下文、F16 注意力 KV/F32 循环状态、4 线程/batch 128、默认思考与采样语义。没有改变模型、vendor 锁版、驱动或本机配置。只新增显式控制及资源/计量，不默认启用优化。

## 2. 实现内容，不作为已验证能力

- `prefix_cache_mib` / `--prefix-cache-mib N`，范围 0–4096，默认 0。PowerShell 入口为 `-PrefixCacheMiB N`。仅支持 CPU、关闭重排的驻留会话；普通 generate/candidate_score 须显式 `--interactive`，system_one 共用驻留权重；GPU/重排组合明确拒绝。
- 进程内单条前缀序列快照，不写磁盘、不保留生成后的会话状态。键包含模型实例/文件身份、锁定上游/构建、执行与语义配置，且核对实际完整 token 前缀。不是按语义相似度命中，也不是搜索任意最长公共前缀的缓存树。
- 对输入长度 N、批量 B，选择 `floor((N-1)/B)*B` 的已完成前缀检查点，保留至少一个后缀批次重新计算最终 logits。原批次边界不改变，采样器每个请求重建并接受完整输入，生成状态不写回前缀。短输入或前缀不匹配不会省略必要计算。
- 使用固定上游 `llama_state_seq_*_ext` 且 `LLAMA_STATE_SEQ_FLAGS_NONE`；源码核对其混合内存序列化依次处理注意力和循环状态。该接口/源码事实不能代替本模型实际恢复与数值验收。
- 替换前先释放旧条目，序列化载荷、token 与键纳入容量上限；写入前再检查物理余量/提交额度。不足时跳过快照并记录状态，完整推理设置保持。恢复 API 返回长度或位置错误时明确失败，不静默采用部分状态或重算掩盖错误。
- 新快照只暂存，完整请求及记录成功后才发布；System One 父请求失败/取消会清空缓存。相关行为已经编码和配置/策略检查，**真实模型命中、隔离、取消及失败发布测试未完成**。
- 新计量包含 `input_reused`、`prefix_cache_status`、`prefix_cache_bytes`、`prefix_restore_s`、`prefix_save_s`。`input_processed` 是新计算的完整批次 token，缓存命中不进入新计算吞吐；System One usage 同样累计新计算 token，逐题指标记录复用量。
- 新增 `--logits-directory NEW_DIR` 用于 interactive 诊断，逐请求保存独立编号的完整词表文件；目录须新建，避免覆盖。该路径在记录中标为 logits diagnostic，不作为正式性能样本。

容量账本额外登记完整配置预算及未知实际占用；启用缓存明确标记需要独立会话校准。现有单请求 CPU 内存包络不能授权缓存会话，校准工具新增拒绝规则；旧构建/配置的校准也不能直接继承。正式缓存性能验收工具/完整会话校准尚未完成。

## 4. 资源阻断与失败记录

最初探测物理可用 RAM 为 2,586,128,384 bytes，保守完整物理预算为 10,415,146,912 bytes，性能准入失败。模型驻留后，无缓存 generation 的下一请求探测约 355MiB 可用、candidate_score 约 901MiB，低于既有 1024MiB 保留线，拒绝继续。默认路径与候选路径均可能遇到该资源约束，不能直接归因为新增快照。

System One 尝试中两次快照均记录 `snapshot_resource_skipped`，`input_reused=0`、实际快照载荷为 0；因此没有获得一次可验证的缓存恢复。三项验收失败原样保留，未改为跳过/通过，也未为了得到性能数字放宽门槛。运行中计时受到分页/后台负载及诊断干扰，不发布本轮 tok/s 或延迟倍数。

本机证据目录：`reports/prefix-cache-1792838305549913000/`（3 项缓存尝试与失败），`reports/performance-20261024-baseline/`（源码参照及缓存关闭回归），`reports/performance-20261024-admission/`（正式入口拒绝），以及构建日志。原始提示/输出、完整 logits、EXE、本机配置与日志不随仓库提交。
