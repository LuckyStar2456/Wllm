# Wllm TUI 与图标设计提案

日期：2026-10-24。最新方向：**纯终端、参考 Spring Boot 启动横幅，大字 `W-LLM` 使用蓝色实心字符作芯、右下阴影体现立体感**；图标仍为透明底、纯白、两侧圆滑向内收的 W。当前已出第三版字符稿与第二版图标，仍未实现新版 TUI 或替换应用图标。现有 `src/terminal.h`、推理代码、依赖和默认配置未改。

## 当前方向：纯终端与大字横幅

- 使用终端自己的背景、配色和等宽字体，纵向排版，正文与日志自然滚动；没有网页式卡片、仪表盘、多栏工作台或大面积自绘底色。
- 启动时一次性显示大字 `W-LLM`，再显示版本、模型、后端、上下文和输入提示符；不在每个请求开始时重新输出大横幅。`W-LLM` 是展示标识，不改项目/命令名称。
- 当前 `banner-v3.ansi` 使用蓝色 `#409EFF` 实心 `█` 作正面，深蓝 `#255A91` 的 `▓` 向右下延伸形成阴影（下移一行、右移一至两列），55 列、6 行。只设置字符前景色，空白处沿用终端背景，不使用图片、背景色块或光效模拟横幅。
- `banner-v3.txt` 保存同一字符稿的无颜色版本；`banner-v3-preview.svg` / `banner-v3-preview.png` 按同一字符与配色生成透明预览，预览图片不是终端运行依赖。蓝色要求只用于大字，不改变纯白应用图标。
- `banner-v2.txt` 保留为 51 列宽的纯 ASCII 回退参考；`terminal-v2.txt` 是上一版首屏示意，展示当前模型/配置及未加载状态，指标均为 `--`，不是实际运行，也未套用第三版横幅。
- 常见 80 列终端可以容纳大字；更窄时使用小字 `W-LLM`。实现时须检查 Unicode 块字符与颜色支持，处理 `NO_COLOR`、ASCII 回退与重定向，不能污染原 stdout 文本或 JSON；这些检测/回退目前仍是待实现要求。
- 参考 [Spring Boot 的启动 Banner 设计](https://docs.spring.io/spring-boot/reference/features/spring-application.html#features.spring-application.banner)，只借鉴启动横幅呈现，不引入 Java/Spring 依赖。

## 首轮方案：已被用户否决，历史保留

| 风格 | 布局与交互 | 适用与取舍 |
|---|---|---|
| 极简对话，旧稿 | 主输出区 + 底部输入 + 单行指标；完整参数按需展开 | 已否决 |
| 分栏工作台 | 左模式导航、中输出与输入、右模型/执行信息 | 生成与 Reflex 切换直观；较占横向空间，窄宽收起侧栏 |
| 推理监控台 | 阶段条、输出区、分阶段指标与事件信息 | 适合当前性能研究；阅读正文时信息密度较高 |
| 复古文本台 | 字符边框、固定区块、文字功能菜单，琥珀/橄榄配色 | 传统终端秩序感强；框线和菜单占用更多行 |

旧交互预览只切换布局/模式示意、不发送请求、不加载模型；其四种风格均不再作为当前备选。按键仍未实现，不把旧稿的“推荐”或预览中的临时选中当作用户采用。

## 当前图标修订：圆滑内收 W

第二版保留 W 的识别形，左右对称，两侧外臂上端以圆弧向中心内收，底部转折圆润，去掉首稿右上方形节点。按用户追加要求，**背景透明，W 纯白 `#FFFFFF`**，没有深色底板或其他装饰。主线和 Reflex 共用同一品牌。该图像颜色不覆盖真实终端自己的文字/背景主题；尚未接入程序。

- `wllm-icon-v2.svg`：当前透明背景、纯白 W 图标修订稿。
- `wllm-icon-v2-512.png` / `wllm-icon-v2-256.png` / `wllm-icon-v2-32.png`：同一 SVG 的预览导出。
- `wllm-mark-v2.svg` / `wllm-mark-v2-256.png`：当前透明标记。
- 无 `v2` 的原图标文件仅作已否决首稿留档，不作为当前推荐资源。

SVG 为确定性矢量草案，PNG 由同一 SVG 渲染，不使用图片生成服务。当前没有 ICO 打包、启动器集成或品牌替换。图标须用户确认，不能称为唯一性/商标审查通过。

真实纯文本 TUI 默认显示 `[W]`，导航用 `>` 生成、`R` Reflex、`M` 模型、`H` 硬件、`=` 参数、`#` 日志、`!` 警告，并保留文字标签。不假定终端可显示 PNG/SVG，不强制 Nerd Fonts/Emoji。Unicode 边框可用时使用，另有 ASCII 回退；图形图标用于支持图像的启动器或后续 GUI。

## 首版待实现范围

1. 键盘导航、输入编辑/多行粘贴、输出滚动及窗口缩放；中文宽度与组合字符需要实际终端验收。
2. 普通生成、直接候选打分与 System One 共用原引擎。Reflex 的 `state/questions` 不使用 ask；普通生成思考/采样和结构化分支语义保持，模式各自输入表单分开。
3. 显示模型/后端/精度/上下文、加载或驻留状态、输入量/复用量、输出量、首 token 或决策时间、生成速率、内存与失败原因；未知值显示 `--`，不把决策生成 0 token 显示成 0 吞吐。
4. 显式模型加载/释放与合作取消；实现时复核原错误/取消的清理边界，不暗中改变生命周期。
5. 参数查看与显式修改，执行中修改仅对后续请求生效；不自动降低精度、缩短 16K 或启用未验收候选。未支持后端/模型标明原因。
6. 本地历史可展示，但不自动拼入输入；当前仍是独立请求，不在界面重命名时暗中变成多轮会话。
7. 保留原 CLI 和 stdout 文本/JSON 重定向能力；TUI 是显式交互入口，非终端环境有可读回退。显示与计算解耦，先按现有 500ms 指标节奏设计，额外内存/CPU与响应性另行测量，不承诺零开销。

首版验收分别检查终端布局/交互、重定向与清理、原推理语义和资源开销。当前只是设计交付，不构成上述功能通过。
